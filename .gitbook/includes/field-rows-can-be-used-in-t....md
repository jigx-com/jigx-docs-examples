{% hint style="warning" %}
Field rows can be used in two places, to avoid confusion here is an explanation:

1. [Field-rows](../../readme/components/field-row.md) used as a standalone component to include input fields/form fields such as [text-fields](../../docs/Components/form/text-field.md) in a single row.&#x20;
2. In the [entity](../../docs/Components/entity/entity.md) component allowing you to place [entity-fields](../../docs/Components/entity/entity-field.md) (read-only) into a single row [field-row.md](../../docs/Components/entity/field-row.md "mention")
{% endhint %}
